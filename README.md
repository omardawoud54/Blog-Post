# 📝 Personal Blog Post Layout

A responsive, stylish, and interactive blog layout designed by **Omar Dawoud**. Built using clean standard HTML5 and custom CSS3, this layout features interactive card animations, custom social media callouts, smooth scrolling, and full mobile responsiveness.

## 🌐 Live Demo

Check out the live page here: [Live Demo](https://omardawoud54.github.io/Blog-Post/)

## ✨ Features

* **Responsive Grid Layout:** Adapts dynamically from a 3-column post grid on desktop down to single-column display on mobile screens.
* **Interactive CSS Animations:** 
  * Cards scale and rotate subtly on hover.
  * Blog post titles feature an animated expanding underline effect.
  * Post images apply a subtle zoom-in transformation.
* **Custom Social Media Section:** Interactive footer cards linking to Facebook, GitHub, and Instagram with platform-specific glow/box-shadow effects on hover.
* **Sticky Navigation Header:** Fixed top navigation with smooth-scrolling anchor links (`#home`, `#about`, `#contact`).

## 📁 File Structure

```
├── index.html       # Main HTML markup containing structure, posts, about, and footer sections
├── css/
│   └── style.css    # Complete stylesheet with CSS Grid, animations, and responsive media queries
└── imgs/            # Asset folder for post images and social media icons
    ├── facebook.png
    ├── github.png
    ├── instagram.png
    └── Screenshot+2025-04-27+at+17.00.18.jpg
```

## 🚀 Getting Started

To run or customize this project locally:

1. Clone or download this repository.
2. Ensure image assets are placed correctly within the `imgs/` folder.
3. Open `index.html` directly in any web browser.
